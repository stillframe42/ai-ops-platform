# 실험 1 — 분석 프롬프트 v1 vs v2 (`analysis-prompt-v2`)

- 기간: 2026-09-15 계약·구현, 2026-09-16 본 실행 (compose, 3종 시나리오 순환)
- 판정 기준(사전 정의, 실행 전 고정): 처리군 Faithfulness 평균 − control ≥ **+0.05** 이고 부트스트랩 95% CI 가 0 을 포함하지 않으며, 건당 비용 증가 **+30% 이내**. CI 가 0 을 포함하면 **보류**.
- 결론: **보류** — Faithfulness 차이 +0.03, 95% CI −0.14 ~ +0.20 (0 포함). 배정이 A 11 · B 4 로 치우쳐(이항 p=0.059, 배정기 자체는 합성 2만 건에서 B 비율 0.498) 처리군 표본이 적다. v1 은 기본값으로 유지하고, 표본을 더 모아 재판정한다.

## 1. 가설

분석 에이전트 시스템 프롬프트에 추론 구조("근거 인용 → 가설 → 반증 확인 → 결론")를 명시하면, 보고서가 재조회 근거와 어긋나는 서술(Faithfulness 실패 유형 A·B)이 줄어 Judge Faithfulness 가 오른다. 비용은 반증 확인 단계의 도구 호출이 늘어 다소 오를 수 있다 — 한도 +30%.

## 6. 판정과 한계

- 판정: **보류** — 사전 기준의 첫 조건(CI 가 0 미포함)에서 멈춘다. 점 추정은 +0.03 으로 기준 +0.05 에도 못 미친다. 비용은 +24% 로 한도 안이지만 CI 상단(+0.096 USD ≈ +87%)은 한도를 넘는다 — 표본이 늘어 F 차이가 유의해져도 비용 조건을 다시 봐야 한다.
- 후속: `RESUME=1 experiment-run.sh analysis-prompt-v2 10` 으로 이어서 표본을 모으거나(회차당 약 12분·0.17 USD), 배정을 균형 배정(시나리오 층화·교대)으로 바꿔 재실행. 승자 없음이므로 기본값 변경 없음.
- 한계
  - 표본: A 11 · B 4. 해시 배정이 15건에서 치우쳤다(이항 p=0.059). 배정기는 합성 id 2만 건에서 B 0.498 로 편향이 없다 — 작은 표본에서 균형을 보장하려면 배정을 해시 대신 시나리오 층화·교대로 바꿔야 한다(ADR-0019 재평가 조건 후보). 데모 인시던트는 3종 시나리오라 실 운영의 다양성을 대표하지 않는다.
  - Judge 포화: 본 실행에서는 F 가 0.4~1.0 으로 갈렸지만(A 11건 중 1.0 이 8건) 상단 밀집은 여전하다 — Judge 가 상단에서 변별력을 잃으면 사전 기준(F +0.05)이 도달 불가능한 기준이 된다. 후속 = 앵커 세분화 또는 Actionability 병행 기준 (`docs/quality-evaluation.md` §7).
  - chaos 재현성: 같은 시나리오라도 발화 시점·창 수치가 매회 달라 인시던트마다 난도가 다르다 — 해시 배정이 시나리오별로 균등하지 않을 수 있다(회차별 variant 는 jsonl).
  - v2 는 스텝 수·partial 률이 오를 수 있다(9/15 재귀 한도 실측) — 성공률·스텝 패널과 함께 본다.
